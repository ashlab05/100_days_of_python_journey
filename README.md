# 100_days_of_python_journey
Touching up my basics and getting strong. Sharing my code I practiced each day here.

## Repository Structure

This repository contains 100 folders (day 1 through day 100) to organize daily Python practice code:

```
100_days_of_python_journey/
├── day 1/
├── day 2/
├── day 3/
...
├── day 99/
└── day 100/
```

Each folder is ready for you to add your Python code files from your daily practice!
